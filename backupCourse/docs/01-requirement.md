# Portfolio Website Requirement

## Project Information

Project Name : ITC Portfolio Website

Version : 1.0

Course : Website Development

---

## Project Objective

สร้างเว็บไซต์ Portfolio ส่วนบุคคล เพื่อแสดงข้อมูล ประวัติ ทักษะ ผลงาน และช่องทางการติดต่อ

เว็บไซต์นี้จะถูกพัฒนาต่อเนื่องตลอดรายวิชา โดยเพิ่มความสามารถใหม่ในแต่ละบทเรียน

---

## Target Users

- ผู้สอน
- นักศึกษา
- ผู้ประกอบการ
- ผู้ที่เข้าชม Portfolio

---

## Website Pages

1. Home
2. About
3. Skills
4. Gallery
5. Contact

---

## Functional Requirements

เว็บไซต์ต้องสามารถ

- แสดงข้อมูลส่วนตัว
- เชื่อมโยงระหว่างหน้า
- แสดงรูปภาพ
- แสดงวิดีโอ
- แสดงเสียง
- รับข้อมูลผ่าน Contact Form
- รองรับ Responsive Design
- พัฒนาด้วย Bootstrap
- ทดลองพัฒนาด้วย Tailwind CSS

---

## Non-functional Requirements

- โหลดได้รวดเร็ว
- ใช้งานง่าย
- รองรับ Desktop และ Mobile
- จัดโครงสร้างไฟล์เป็นมาตรฐาน
- Deploy บน Netlify

---

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Tailwind CSS
- Git

- Netlify
