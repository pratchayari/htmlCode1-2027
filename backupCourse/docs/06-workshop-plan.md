# Workshop Plan

Project Name : ITC Portfolio Website

---

# Workshop Objective

นักศึกษาจะพัฒนาเว็บไซต์ Portfolio จำนวน 1 เว็บไซต์
โดยเพิ่มความสามารถใหม่ในแต่ละ Sprint

เว็บไซต์จะถูก Deploy ไปยัง GitHub และ Netlify ทุก Sprint

---

# Sprint Overview

| Sprint | Topic | Duration | Deliverable |
|---------|--------|----------|-------------|
| Sprint 1 | HTML + CSS | 12-16 Hours | Website Structure |
| Sprint 2 | Links & Multimedia | 12-16 Hours | Multi-page Website |
| Sprint 3 | Forms + CSS | 12-16 Hours | Contact Form |
| Sprint 4 | Responsive Design | 12-16 Hours | Responsive Website |
| Sprint 5 | Bootstrap + Tailwind | 12-16 Hours | Modern Portfolio |

# Success Criteria

เมื่อสิ้นสุดโมดูล นักศึกษาจะสามารถ

- พัฒนาเว็บไซต์หลายหน้า
- ใช้งาน HTML และ CSS ได้
- สร้าง Contact Form
- ออกแบบ Responsive Website
- ใช้งาน Bootstrap
- อธิบายความแตกต่างระหว่าง Bootstrap และ Tailwind
- ใช้งาน GitHub และ Netlify ในการเผยแพร่เว็บไซต์
